   - Dự án tiêu biểu & Đối tác chiến lược (Petrovietnam, PTSC, Vietsovpetro, PV Gas, BSR, LSP, EVN).
   - Tin tức mới nhất & Footer chuẩn Canh Cam.

   - *Lịch sử hình thành và phát triển* (Timeline từ 2011 đến nay)

   - 5. Bảo dưỡng, sửa chữa thiết bị, hệ thống cơ khí
   - 6. Bảo dưỡng, sửa chữa và nâng cấp hệ thống, thiết bị điện và tự động

## 2. HƯỚNG DẪN KHỞI CHẠY WEB

Trang web được xây dựng độc lập, không phụ thuộc framework cồng kềnh, có thể chạy trực tiếp bằng cách:

### Cách 1: Chạy Server tích hợp sẵn (Khuyên dùng)
Yêu cầu đã cài Node.js (đã có sẵn trong máy):
```bash
npm start
# hoặc
node server.js
```
Truy cập trình duyệt tại địa chỉ: `http://localhost:3000`

### Cách 2: Mở trực tiếp file HTML
Bạn có thể mở trực tiếp bất kỳ file nào (`index.html`, `gioi-thieu.html`, `dich-vu.html`,...) bằng trình duyệt Google Chrome, Edge hoặc Firefox.
